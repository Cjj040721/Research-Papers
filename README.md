## 3. Evidence and Permissions

This repository deliberately separates **reported results** from **independently reproduced results**. No accuracy value should be read as a new evaluation performed for this collection.

- The AR3 paper is included under **CC BY-NC 4.0**, with author attribution preserved.
- The RCBT IEEE Xplore download is not redistributed here; use the DOI link instead. Its historical experiment source and logs remain local, while a separate [2026 implementation](https://github.com/Cjj040721/RCBT-Movie-Sentiment) provides a new sequence-preserving workflow. The archived log corroborates the reported training losses and best test accuracy, not a new independent reproduction.
- The OD-GCResNet manuscript is not included. Its official code and dataset are linked from the collaborator's repository.
- Both 2023 modelling report PDFs are included with team permission. Junjia Cao was responsible for all code and mathematical modelling in both team projects. Their historical source packages were not recovered; separate 2026 implementations provide new verified code rather than claimed reproductions.
- `Code: Not archived` means no reliable source package has been located; it does not imply that code is coming soon.
- Simulated ablation figures found in the local OD-GCResNet materials are excluded because they were generated by simulation functions rather than training logs.
- Acceptance letters, publication certificates, and administrative documents are intentionally excluded. Author contact details already present in a licensed publication are preserved.
